# PVRIG Final50：比赛评分、表达纯度、可开发性与 VHH-hFc 格式风险复核

日期：2026-07-25  
审查对象：`node1/pvrig_final50_structure_bundle_v1_20260725_local`  
官方评分文件：`机制/official_reference/附件7_抗体赛道实验测试流程与评分规则.pdf`

## 1. 结论先行

上一份报告确认了 Final50 总体具有较强的 PVRIG-PVRL2 blocker-like 几何。本次加入官方实验评分后，判断需要进一步收紧：

> **当前筛选流程对“是否可能挡住 PVRL2”处理得较好，但对“能否以 VHH-hFc 在统一 CHO/Protein A 工艺下高产、形成高纯单体并产生可拟合 BLI 曲线”的证据仍明显不足。**

当前不能从已有 proxy 得出：

```text
预计 Yield >100 mg/L
预计 SDS/HPLC 纯度 >=90%
预计 BLI response >=0.1 nm
预计 Kd 或 IC50
```

更准确的表达是：

```text
我们已经完成序列/结构层面的制造风险前筛；
尚未完成对主办方真实表达量、纯度和 BLI 分类的校准预测。
```

Final50 的序列风险分层结果：

| 层级 | 数量 | 含义 |
|---|---:|---|
| `D1_LOWER_RISK_PROXY` | 19 | 当前序列 proxy 中未发现主要制造风险，但不等于会高表达或高纯 |
| `D2_REVIEW` | 19 | 存在边缘 VHH 属性、表达/纯度 proxy 或 conservative gate 风险 |
| `D3_HIGH_REVIEW` | 12 | 存在 `single_domain_suitability=poor`、低表达 proxy 或高 instability 等明显复核项 |

Top10 中：

```text
D1：#2、#6、#7、#9
D2：#1、#3、#4、#5
D3：#8、#10
```

因此，结合上一轮机制审查，当前最适合做第一批实验核心的仍是：

```text
Top10 #2、#6、#7
```

其中 #9 可作为 PVRIG-38 parent diversity 对照加入；#8 和 #10 不宜只因 blocker-like 几何强就列为第一批制造优先项。

## 2. 官方评分改变了哪些优先级？

## 2.1 最终实验分子不是裸 VHH，而是 VHH-hFc

官方附件明确规定：

```text
候选形式：VHH-hFc
表达：4 mL 或 10 mL CHO 瞬时表达
序列处理：统一密码子优化
纯化：Protein A 等亲和纯化，一步纯化
个性化工艺：原则上不接受
```

这意味着主办方测试的是：

```text
VHH–linker/hinge–human Fc 同源二聚体
```

而当前多数结构判断基于：

```text
单个裸 VHH + 单个 PVRIG
```

二者之间存在四个重要差异：

1. Fc 会使构建体二聚化，形成两个 VHH 结合臂；
2. VHH C 端会连接 linker/hinge/Fc，端点几何可能改变 paratope 可及性；
3. Fc 二价性可能在固定化实验体系中产生 avidity/rebinding；
4. Protein A 低 pH 洗脱可能放大酸敏感、聚集和 clipping 风险。

上一轮 400-pose 端点审查显示：

```text
N 端接触 PVRIG：330/400
C 端接触 PVRIG：0/400
```

因此，当前 pose 支持常规的：

```text
VHH–C端–linker/Fc
```

但仍需要对**最终 VHH-hFc 构建**做格式级检查，而不是只检查裸 VHH。

## 2.2 初筛实际权重

官方初筛：

```text
初筛综合分
= 0.70 × BLI 单浓度得分
+ 0.20 × Yield 得分
+ 0.10 × 纯度得分
```

### BLI 单浓度

| 结果 | response shift | 得分 |
|---|---:|---:|
| 结合 | `>=0.1 nm` | 100 |
| 弱结合 | `0–0.1 nm` | 50 |
| 不结合 | `<0 nm` | 0 |

### Yield

| Yield | 得分 |
|---|---:|
| `>100 mg/L` | 100 |
| `25–100 mg/L` | 60 |
| `<25 mg/L` | 0 |

### 纯度

| 纯度 | 得分 |
|---|---:|
| `<80%` | 60 |
| `80–90%` | 80 |
| `>=90%` | 100 |

几个直接推论：

```text
强结合 + 25–100 mg/L + >=90%纯度 = 92 分
强结合 + 25–100 mg/L + 80–90%纯度 = 90 分
弱结合 + 最优表达 + 最优纯度 = 65 分
不结合 + 最优表达 + 最优纯度 = 30 分
```

所以：

> **BLI 是第一决定因素，Yield 是第二决定因素。**

纯度连续权重只有 10%，但样品量或质量不足可能导致无法完成检测，属于评分公式之外的实际淘汰风险。

## 2.3 复筛仍然是 Kd 与 IC50 各占一半

```text
5 浓度 BLI → Kd 排名得分
竞争 ELISA → PVRIG-PVRL2 blocking IC50 排名得分
复筛综合分 = 0.50 × Kd + 0.50 × IC50
```

因此最优候选必须同时具备：

```text
能制备
+ 能被Protein A工艺获得足够高质量样品
+ 单浓度BLI明确结合
+ 多浓度曲线可可靠拟合
+ 竞争ELISA真实阻断
```

## 3. Final50 当前可开发性数据概况

## 3.1 已有的好信号

Final50：

- 50/50 通过当前 developability hard gate；
- 50/50 没有异常 Cys 计数；
- 50/50 没有 `N-X-S/T` 非预期 N-糖基化 motif；
- 50/50 NanoBodyBuilder2 结构生成成功且序列匹配；
- 全局 GRAVY 范围为 `-0.615–0.061`，仅 1 条高于 0；
- pI 范围为 `4.74–8.77`，没有极端高碱性序列；
- TNP 总状态为 50/50 PASS。

这些结果支持：

> Final50 没有明显的大规模序列污染、异常游离 Cys、连续强疏水或非预期糖基化问题。

## 3.2 需要正视的风险

### Conservative gate

```text
通过：32/50
未通过：18/50
```

### VHH 单域适合度

```text
good：33
borderline：7
poor：10
```

parent 分布具有明显规律：

| parent | good | borderline | poor |
|---|---:|---:|---:|
| HR-151/151 | 15 | 0 | 0 |
| PVRIG-38 | 10 | 0 | 0 |
| 151H7 | 8 | 7 | 0 |
| 151H8 | 0 | 0 | 10 |

这说明：

> `single_domain_suitability=poor` 不是随机分散，而是集中在 151H8 parent。

它既可能代表 151H8 人源化框架被当前 VHH 规则误判，也可能代表真实的单域溶解/表达风险。由于 151H8 来源于成功专利系列，不能简单 hard delete；但在统一 VHH-hFc/CHO 工艺下仍应独立验证。

### Expression proxy

```text
范围：60–86.5
26/50 集中在 85
```

当前 expression proxy 主要由：

```text
pI
净电荷
instability index
Cys
AbNatiV
Sapiens suggested mutations
```

构成。它没有使用真实 CHO titer 训练校准，且没有模拟完整 VHH-hFc 的分泌和装配。

因此：

```text
expression_score=85
```

不能翻译为：

```text
预计 Yield=85 mg/L
```

两者不是同一量纲。

### Purity/aggregation proxy

```text
47/50 得分为 100
1/50 得分为 90
2/50 得分为 80.4
```

这说明 purity proxy 已出现明显饱和。

它主要由：

```text
global GRAVY
连续 5-aa 疏水 run
Cys 数
polyreactivity proxy
TNP PSH/PPC/PNC flags
```

构成，但尚未直接评估：

- 完整 VHH-hFc 的 SEC 主峰；
- Fc 二聚体中的界面和空间拥挤；
- Protein A 低 pH 洗脱诱导聚集；
- clipping/降解产物；
- 非还原条件下错误多聚体；
- 工艺相关杂质。

因此当前 47 条“100 分”不能解释成 HPLC 纯度会达到 90% 以上。

### 结构质量字段未提供区分度

```text
structure_score：50/50 均为 60
structure_quality_flag：40 NOT_RUN + 10 SKIPPED
FR_RMSD_cross_tool：50/50 为空
```

NanoBodyBuilder2 成功只能证明产生了模型，不能证明：

```text
热稳定性好
CHO中正确折叠
Protein A洗脱后保持单体
VHH-hFc不聚集
```

## 3.3 PTM/化学稳定性

### 好消息

在 IMGT CDR 中：

```text
N-X-S/T 糖基化 motif：0/50
NG/NS/NT 脱酰胺 motif：0/50
```

### 需要复核

```text
CDR 中含 DG/DS/DD/DT 异构化提示：34/50
CDR 中含 DP 酸裂解提示：15/50
```

Top10 中只有 #2 和 #3 没有本次规则标出的 CDR 异构化/DP motif。

特别是：

```text
Top10 #8：CDR3 有 DP
Top10 #10：CDR3 有 DS，并有两个 DP
```

DP 对本赛题尤其值得关注，因为 Protein A 常涉及酸性洗脱。但 motif 只能作为 review flag，不能直接判定会发生剪切。临床抗体研究表明，脱酰胺和异构化高度依赖局部结构、溶剂暴露、pH 和时间；仅凭序列 motif 会明显过预测。

当前表中的 `oxidation_risk_count=5–8` 实际上更接近对 M/W 残基的计数，不是氧化事件概率。它不应直接进入 hard gate。

## 5. 当前筛选流程哪些地方合适？

## 5.1 合适

1. 已将 binding 与 blocking 分开；
2. 已有 ANARCI/IMGT、官方 validator 和阳性相似性排除；
3. 已检查 Cys、N-糖基化、疏水 run、pI、净电荷、GRAVY 和 instability；
4. 已加入 AbNatiV、Sapiens 和 TNP；
5. 已把表达、纯度和 developability 分成不同字段；
6. 已明确这些分数是 proxy，不等于湿实验结果；
7. 已使用多 seed、双结构和 blocker-like geometry；
8. 已保留 parent 和 CDR3 多样性信息。

这些足以作为第一轮计算风险筛选。

## 5.2 不足

### 1. 初筛 proxy 尚未按官方实验校准

当前 `initial_screen_proxy_score=71.71–89.49` 使用的是：

```text
weak binding prior
+ sequence expression proxy
+ sequence purity proxy
```

但官方使用的是：

```text
离散 BLI class
+ 实测 mg/L
+ 实测 SDS/HPLC purity
```

两者不可直接比较。

尤其是当前 `binding_evidence_status=AVAILABLE` 容易产生误导；其真实边界应改写为：

```text
WEAK_COMPUTATIONAL_PRIOR_ONLY
```

### 2. purity proxy 严重饱和

47/50 得到 100，无法区分谁更可能达到：

```text
<80%
80–90%
>=90%
```

应增加结构表面疏水 patch、局部电荷 patch、自相互作用和完整 VHH-hFc 格式风险，而不是继续使用 global GRAVY 作为主要依据。

### 3. TNP 分量证据不完整

虽然 50/50 `tnp_status=PASS`，但：

```text
24/50 的六项 TNP component flags 未导出
24/50 为完整 green
2/50 含一个 amber PSH flag
```

在分量缺失时，不能把总 PASS 当成与完整六项 green 完全等价。

### 4. 计算可开发性不能预测 CHO Yield

CHO 瞬时表达受以下因素共同影响：

- 翻译和分泌效率；
- VHH 折叠和质量控制；
- Fc 装配；
- 细胞内降解；
- 培养体系；
- 序列局部结构；
- 蛋白在上清中的稳定性。

现有 pI、AbNatiV 和 Sapiens 等特征只能筛风险，不能给出可靠 mg/L。

### 5. 缺少完整 VHH-hFc 模型

当前 format-designability 只用了 VHH 端点接触。

至少还需检查：

```text
VHH C端到Fc N端的linker长度
Fc二聚后两条VHH是否互相碰撞
两个VHH是否同时可接近膜面PVRIG
Fc体积是否挡住PVRIG-PVRL2阻断pose
是否产生不合理的高局部有效浓度/自相互作用
```

### 6. 缺少实验可开发性正交指标

权威研究通常联合使用：

```text
SEC-HPLC/UPLC主峰
还原/非还原SDS或CE-SDS
Tm / Tagg
DLS或SLS
HIC/SMAC
AC-SINS或CIC自相互作用
polyreactivity/PSR
cardiolipin、dsDNA、BVP、PLE等非特异性面板
```

单一计算评分无法覆盖这些不同失效模式。

## 6. 建议的新版筛选结构

不建议把所有指标继续压成一个总分。建议采用分层 gate + Pareto 组合：

## Gate A：比赛合规

```text
官方 validator
ANARCI/IMGT
CDR identity <0.80
标准氨基酸
完整 VHH
```

## Gate B：VHH-hFc 制造风险

```text
异常/奇数 Cys
非预期 N-X-S/T
严重疏水 run
single-domain suitability
AbNatiV / framework naturalness
结构表面 hydrophobic patch
结构表面正/负电荷 patch
完整 TNP 分量
```

## Gate C：化学稳定性

```text
CDR 中 NG/NS/NT
CDR 中 DG/DS/DD/DT
CDR 中 DP
M/W 的结构暴露
motif 是否位于 paratope
motif 突变是否破坏 binding pose
```

注意：

> motif 只用于 review；必须结合结构暴露和功能敏感性，不能机械 hard fail。

## Gate D：最终格式

```text
构建 VHH-hFc 同源二聚模型
linker/Fc clash
paratope accessibility
膜面方向
二价几何
Protein A低pH风险
```

## Gate E：机制与结合

```text
独立 binding prior
无约束/弱约束 redocking
PVRIG-PVRL2 interface occlusion
多 seed / 双构象
decoy/off-target specificity
```

## Gate F：组合选择

最终 50 条不只取总分前 50，而应保留：

```text
机制强 + 制造低风险核心
不同 parent
不同 CDR3 cluster
不同 R95 依赖方式
不同 format-risk 水平的校准对照
```

## 7. 最优先新增的计算检查

按对比赛结果的实际影响排序：

### P0：立即做

1. 把官方评分离散规则写入 pipeline，而不是只保留连续 proxy；
2. 将 `binding_evidence_status=AVAILABLE` 改成 `WEAK_COMPUTATIONAL_PRIOR_ONLY`；
3. 将 24 条缺失的 TNP 六项分量补齐；
4. 对 Final50 计算结构表面疏水 patch 和正/负电荷 patch；
5. 对 CDR 中 DG/DS/DD/DT、DP 做结构暴露和 paratope 位置加权；
6. 为 Top10 构建统一的 VHH-hFc/linker 结构模型；
7. 将 #8/#10 作为 format/high-risk review，不与 #2/#6/#7 同置信等级；
8. 保留 #9 作为 PVRIG-38 parent diversity。

### P1：有资源时做

1. 用已知 PVRIG VHH 阳性构建作为表达/格式正对照；
2. 对 VHH-hFc 做低 pH 短时结构/聚集敏感性比较；
3. 增加 decoy/off-target specificity；
4. 用任何可获得的 CHO Yield、SEC 主峰、BLI 和 IC50 数据重新校准；
5. 将 actual Yield/purity/BLI 回填后，再训练或拟合正式排序模型。

## 8. 当前最重要的判断

> **机制对，不等于能赢初筛。**

现有 Final50 的最大优势是阻断界面方向明确；最大短板是：

```text
没有真实 CHO Yield
没有真实 SDS/HPLC purity
没有真实单浓度 BLI
没有最终 VHH-hFc 格式结构验证
```

当前筛选流程适合继续作为：

```text
机制富集
+ 序列风险排雷
+ 候选组合选择
```

但不应把：

```text
expression_score
purity_aggregation_score
initial_screen_proxy_score
```

解释为主办方实验分数。

如果只能从 Top10 选最稳的一组，建议：

```text
#2 + #6 + #7
```

再加入：

```text
#9：parent/机制多样性
#3 或 #4：第二层制造风险
#1 或 #5：高阻断几何但需制造复核
```

#8 和 #10 更适合作为“151H8 格式风险验证组”，而不是唯一主力。

## 9. 证据边界

本报告中的 D1/D2/D3 是本项目内部的 **proxy risk tier**：

- 不是主办方官方等级；
- 不是实际 Yield 分组；
- 不是实际纯度分组；
- 不是药品开发放行标准；
- 不应单独用于删除已知成功 parent。

真实结果仍必须由：

```text
CHO表达
Protein A纯化
SDS-PAGE/HPLC
BLI
竞争ELISA
```

决定。
