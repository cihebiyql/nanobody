## 3. 第二层：融合兼容性实际检查了什么？

## 3.1 已完成的窄范围检查

在每个冻结 VHH-PVRIG pose 中检查：

1. VHH C 端末残基的溶剂可及面积；
2. C 端与 PVRIG 的最小原子距离；
3. 从末端主链 C/CA 延伸 35 Å 的直线退出方向是否穿过 PVRIG；
4. VHH 侧最后 10 aa 是否形成异常连续疏水尾；
5. VHH 内 Cys 数量、预测二硫键配对和暴露未配对 Cys；
6. 上述结果在 4 seeds × 2 构象中是否重复出现。

本轮 22 条候选：

```text
最小 C端-PVRIG 距离范围：25.80–35.02 Å
C端末残基中位 SASA 范围：118.52–138.02 Å²
序列 Cys：全部为 2 个
C端尾部疏水残基：2–3 个
C端尾部最大连续疏水长度：不超过 2
```

所有候选均为：

```text
F1_CLEAR_NARROW_PRECHECK
```

这支持常规的：

```text
VHH–C端–linker/hinge–Fc
```

但这里只证明 VHH 端点没有明显被 PVRIG 埋住。

## 3.2 当前不能完成的全长 VHH-hFc 检查

官方材料目前只明确：

```text
候选以 VHH-hFc 形式进行 CHO 瞬时表达和 Protein A 纯化
```

尚未公开：

- VHH 与 hinge/Fc 间的精确 linker；
- hinge 的精确边界和长度；
- Fc 亚型、突变和链间二硫键设计；
- 完整单链序列；
- 同源二聚体建模定义。

因此以下项目被明确标记为 `DEFERRED_EXACT_CONSTRUCT_REQUIRED`：

| 待检查项 | 当前状态 |
|---|---|
| Fc 是否与 PVRIG 碰撞 | 等待精确 linker/hinge/Fc |
| Fc 是否与另一个 VHH 臂碰撞 | 等待精确二聚体构建 |
| 两个 VHH 臂是否同时暴露 | 等待精确二聚体构建 |
| 是否可形成合理二价结合 | 等待精确二聚体构建与实验体系几何 |
| 完整 fusion junction 疏水性 | 当前只完成 VHH 一侧尾部 |
| hinge/Fc 额外 Cys 是否错误连接 | 等待精确 Fc/hinge 序列 |

此前通用 hFc Chai-1 pilot 的 ipTM 较低，已冻结为 `NO_EXPANSION`；不能用任意通用 Fc 构建替代赛事方真实构建并据此重排候选。

## 3.3 获得精确构建后的固定规则

获得赛事方完整构建后，只对优先 Top20 做全格式检查：

```text
精确 VHH-linker-hinge-Fc 同源二聚体
→ 多 seed 全长预测
→ 将两个 VHH 头部分别叠合到冻结裸 VHH pose
→ 计算 Fc/PVRIG、Fc/VHH、VHH/VHH clash
→ 检查两臂暴露、linker 可达性和二价几何
→ 检查 junction/hinge Cys 与疏水暴露
```

结果只允许：

```text
严重、跨 seed 重复的不可修复碰撞 → hard fail
轻度/模型依赖问题 → tie-breaker warning
```

不得让低置信全长模型完全取代已经较稳定的裸 VHH docking。

## 4. 第三层：A/B/C 表达与纯度风险等级

本轮没有创建连续的：

```text

purity_score
预计 mg/L
预计纯度 %
```

原因是当前没有赛事体系下的 CHO Yield、SDS-PAGE/HPLC 纯度、SEC 主峰、Tm、Tagg 或 BLI 实测校准数据。

## 4.1 C 级：hard risk

任一项触发即进入 `C_HIGH_RISK`：

- 融合预检 hard fail；
- `poor/not_vhh_like`；
- 奇数或无法解释的额外 Cys；
- CDR N-糖基化 motif；
- 5 连疏水；
- 极端表面疏水 patch（同时达到 `>=20 residues` 和 `>=1000 Å²`）；
- 至少 2 个 TNP red。

C 级不进入前排。

## 4.2 B 级：需要复核

无 C 级硬风险，但出现任一项：

- borderline VHH；
- AbNatiV VHH `<0.70`；
- Sapiens `<0.70`；
- conservative gate 未完全通过；
- 1 个 TNP red 或任意 TNP amber；
- 表面疏水 patch `>=15 residues` 或 `>=900 Å²`；
- DP 等酸敏感位点在多 pose 中暴露；
- instability index `>=40`；
- 融合预检 warning。

B 级可以保留少量机制强候选，但不能占满 Top10。

## 4.3 A 级：较低计算风险

没有触发上述 C/B 条件，记为：

```text
A_LOWER_RISK
```

A 只表示当前计算检查未发现主要风险，不表示：

```text
Yield >100 mg/L
纯度 >=90%
SEC 单体比例高
一定不会聚集
```
