## 4. 独立结构复算方法

不能直接将 bundle 中的 docking PDB 与原始 8X6B/9E6Y 做空间遮挡计算，因为两者不在同一坐标系。

本次对每个 PDB 执行：

```text
1. 提取 docking pose 中 PVRIG chain T 和 VHH chain A；
2. 用同源 PVRIG Cα 原子执行 Kabsch 叠合；
3. 将原始 8X6B/9E6Y 中的 PVRL2 变换到 docking pose 坐标系；
4. 用 4.5 Å 重原子距离重算：
   - PVRIG-VHH residue-pair contacts
   - PVRIG hotspot overlap
   - PVRL2-VHH residue-pair occlusion
   - CDR1/CDR2/CDR3 遮挡贡献
5. 用 2.0 Å 检查 PVRIG-VHH 直接严重碰撞；
6. 按候选聚合 8 个 pose 的最小值、中位数、最大值和通过比例。
```

复算明细：

```text
机制/data/audits/PVRIG_Final50_400pose_机制复核明细.tsv
机制/data/audits/PVRIG_Final50_候选级机制复核汇总.tsv
```

## 9. 当前流程做得正确的地方

### 9.1 Binding 与 blocking 分开

流程没有把 sequence binding prior、HADDOCK score 或 hotspot contact 单独当作 blocker，而是要求 PVRL2 interface occlusion。

这符合已有成功案例的核心逻辑：

> 能结合 PVRIG 是必要条件，但不是 PVRIG-PVRL2 blocker 的充分条件。

### 9.2 使用双结构、多 seed

8X6B、9E6Y 分开 docking，再取共识，比只使用一个结构可靠。

### 9.3 Paratope 主要由 CDR 驱动

400-pose 审计显示：

- PVRIG 接触残基中位 90% 来自 CDR；
- CDR3 接触比例中位约 47%；
- 没有出现大批完全依靠 framework 平贴 PVRIG 的假 paratope。

### 9.4 阳性泄漏控制有效

Final50：

- 50/50 官方 validator PASS；
- 50/50 ANARCI/IMGT 成功；
- 最大已知阳性 CDR identity 为 0.714，低于 0.80；
- 50 条 CDR3 均唯一。

## 10. 当前流程的主要不足

### 10.1 Hotspot/CDR 约束 docking 存在循环偏倚

当前 docking 被引导到 PVRIG-PVRL2 界面，之后又用“是否覆盖该界面”进行评价。

它能回答：

```text
该 VHH 是否能够形成阻断样姿势？
```

但不能独立证明：

```text
该阻断样姿势是否是真实最可能的结合姿势？
```

突变控制已经暴露这一风险：

- 12 个 CDR3 disruptive/alanine mutant 仍保留 A-level 信号；
- 其中 3 个仍有 consensus A；
- 81 个阈值设置中仅 4 个保持默认 case-level calls。

因此当前标签必须继续写作：

```text
blocker-like geometry under the constrained docking protocol
```

### 10.2 Blocking score 饱和，并重复计入 robustness

当前：

```text
blocking_consensus_score
= 70% threshold-normalized geometry
+ 30% pose robustness
```

几何指标达到门槛即被截断为 100。Final50 的几何普遍超过门槛，因此 `common4_blocking_consensus_score` 仅分布在约 97.2–99.9，区分度很低。

生产分又加入：

```text
40% blocking consensus
+ 20% pose robustness
```

由于 blocking consensus 内已包含 30% robustness，robustness 的有效权重约为：

```text
0.40 × 0.30 + 0.20 = 0.32
```

建议下一版本：

- 保留连续几何值，不在门槛处完全饱和；
- 使用 8 个 job 的低分位数或下置信界；
- robustness 独立计分一次；
- 不再在 blocking 内部和生产分中重复加权。

### 10.3 阳性与突变校准的分辨率仍有限

11 条专利阳性、109 个 pose 中：

- consensus A：3；
- single-baseline A：36；
- B：57；
- E：13。

说明当前规则对真实阳性的召回并不高。

另一方面，部分破坏性 CDR3 突变仍保留 A 信号，说明 specificity 也未完全解决。

### 10.4 独立 affinity 证据不足

当前 `binding_score` 是 weak prior。

已有阳性 benchmark 表明：

- PRODIGY 只能作弱先验；
- FoldX/Rosetta 未证明可跨候选可靠排序；
- 不能把计算分数解释成 Kd。

Final50 中 PRODIGY 与 Rosetta 还存在明显方向不一致。该现象不能直接判定候选不结合，但说明当前没有强正交能量证据支撑最终排名。

### 10.5 Parent/机制多样性不足

Final50 parent 来源：

```text
151H7：15
HR-151/151：15
151H8：10
PVRIG-38：10
```

即：

```text
40/50 = 80% 来自 151 family
```

Top10 中 9/10 来自 151 family，只有 1 条来自 PVRIG-38。

序列 CDR3 虽然多样，但结构 parent/机制多样性有限。若 151 的预测姿势存在系统偏差，候选可能相关失败。

### 10.6 MD 覆盖和解释边界

- 仅 11/50 运行 MD；
- Top10 中只有 #1、#6 有 MD；
- 当前 MD 为 PVRIG-VHH 二元复合物；
- 不包含 PVRL2。

因此 MD 只能支持二元接触稳定，不能直接证明动态 PVRL2 阻断保持。

## 11. 代表 PDB 与 job-level 标签不完全等价

manifest 的 `representative_pair_label` 是 job-level 结论，而交付 PDB 固定为 `cluster_1_model_1`。

本次发现 11 个实际代表 PDB 未通过全部四项门槛，但其 job label 仍可能是 `STRICT_A`。

合理解释是：

- job-level 标签来自多个 selected models 的综合或最佳模型对；
- `cluster_1_model_1` 不一定是触发该标签的实际模型。

后续结构包应为每个 job 提供：

```text
真正触发 native/cross representative-pair 标签的具体 PDB
该 PDB 自身的四项机制指标
model-level label
job-level aggregate label
```

不能把 job-level 标签直接解释成当前交付 PDB 的 model-level 标签。

## 13. Fusion 格式的新几何洞察

对每个 VHH 的前五个和后五个残基进行端点检查：

- N 端与 PVRIG 接触：330/400；
- C 端与 PVRIG 接触：0/400。

因此，针对当前主要 docking 姿势：

> **VHH 的 C 端总体比 N 端更适合作为 linker/Fc 融合端点。**

即：

```text
VHH–linker–Fc
```

通常比：

```text
Fc–linker–VHH
```

更符合当前 paratope 可及性。

但该结论还没有加入：

- PVRIG 膜面方向；
- Fc/linker 真实体积；
- 二价构型；
- 双抗另一臂；
- 细胞表面 co-engagement。

因此它是 format-designability 方向判断，不是完整格式证明。
