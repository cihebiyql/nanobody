# Data and evidence

- `submission/`: official Top50 deliverables, audit, final FASTA, Excel export,
  and the one-row-per-candidate traceability table.
- `qc/`: compact QC outputs (ANARCI/IMGT, AbNatiV, Sapiens, validator and static
  docking metrics) for the final portfolio only.
- `targets/`: public PDB inputs and compact interface/restraint artifacts.
- `provenance/`: the parental CDR authority, source-manifest hashes, and model
  acquisition information.  Large campaign pools are intentionally omitted.
